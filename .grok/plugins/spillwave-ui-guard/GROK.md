# Spillwave UI Guard — Grok Build Instructions

When working on UI in this repository:

1. Start every meaningful UI change by creating or updating the wireframe (`ui-require-wireframe` skill).
2. Treat the acceptance criteria in the wireframe as the source of truth.
3. After implementing, run an adversarial review (`ui-adversarial-reviewer`).
4. Only treat the task as complete after a PASS (or accepted PASS WITH NOTES).
5. Keep builder and critic roles separate.

See the shared `ui-standards` skill for the full contract.
